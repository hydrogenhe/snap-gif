# snap-gif

macOS 截图和 GIF 录制工具。打开 App 会显示操作窗口，也可以从 Dock 再次打开。捕获内容在本机处理，截图会自动复制到剪贴板。

- **⌃⌥5**：框选截图，复制 PNG。
- **⌃⌥6**：框选录制区域。框下点「开始」，再点「停止」或「停止并丢弃」。快捷键也可依序开始、停止和只复制，通常最长 15 秒。30/60 fps 录制大区域时，工具条会显示更短的上限。
- **GIF 图库**：主窗口默认显示最近 10 条历史 GIF，可以预览、复制、另存为或移到废纸篓。「打开存储文件夹」会在 Finder 中打开全部 GIF。录制停止后，在框下选「只复制」「保存并复制」或「丢弃」。只复制会使用临时文件供粘贴，不进入图库。两种复制成功后都会保留同一个框，点「开始」或按 GIF 快捷键直接录下一段；点「取消」关闭录制框。选中作品后可查看实际像素尺寸、总帧数和文件大小。
- **Esc**：取消框选。
- 主窗口 → **快捷键设置…**：可分别自定义截图和 GIF 快捷键。点击要修改的快捷键并按下新组合键。

首次使用时，在主窗口点「申请录屏权限…」直达系统设置的「录屏与系统录音」，允许 snap-gif 后重新打开应用。屏幕区域以发起捕获时指针所在的显示器为准。主窗口可设置目标帧率 4、8、12、16、30 或 60 fps，以及 480、720 或 960 像素的最长边上限。实际尺寸不会放大超过所选区域的原始像素。30/60 fps 使用连续采集；实际帧率取决于屏幕刷新率和采集条件，部分应用会放慢 60 fps GIF 的短帧。复制 GIF 时，剪贴板提供动图数据和原文件，可粘贴到支持 GIF 或文件粘贴的应用。目标应用如果不接受 GIF 粘贴，可从图库打开存储文件夹并上传原文件。

GIF 默认存放于 `~/Library/Application Support/snap-gif/GIFs`。主窗口点「更改存储位置…」可选择其他文件夹，已有文件仍留在原位置。

若 macOS 在更新后要求重新添加录屏权限，在捕获失败提示里点「复制位置并打开设置」。在系统设置点加号，按 ⌘⇧G 并粘贴，然后选择 snap-gif。

需要 macOS 14 或更新版本。安装 Xcode Command Line Tools 后，可运行：

```sh
./build.sh
open build/local.noindex/snap-gif.app
```

## 安装与更新

从 [GitHub Releases](https://github.com/hydrogenhe/snap-gif/releases/latest) 下载适合你的 Mac 的 DMG。打开它，把 **snap-gif** 拖到窗口里的 **Applications（应用程序）**，以后就能从 Mac 的「应用程序」列表搜索打开。需要 macOS 14 或更新版本，可选 Apple 芯片版（arm64）或 Intel 版（x86_64）。也可以下载 ZIP，解压后把 App 拖到「应用程序」。

下载和 App 内更新都无需 GitHub 登录。在主窗口点「检查更新…」会立即查询 GitHub。App 也会在启动时和每运行 6 小时自动检查。有新版时会弹出提示，点「是，下载并安装」才会安装并重新打开 App。点「否，暂不更新」后，同一版本不再自动提醒，仍可手动检查。v0.3.3 及更新版本可直接通过 App 升级。

当前安装包未经 Apple 公证，首次从浏览器下载并打开时，macOS 可能会拦截。参见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。
