# snap-gif

macOS 截图和 GIF 录制工具。打开 App 会显示操作窗口，也可以从 Dock 再次打开。捕获内容在本机处理，完成后自动复制到剪贴板。

- **⌃⌥5**：框选截图，复制 PNG。
- **⌃⌥6**：框选录制区域。框下点「开始」，再点「停止并保存」；也可再次按快捷键开始或停止，最长 15 秒。
- **GIF 图库**：主窗口默认显示最近 10 条历史 GIF，可以预览、复制、另存为或移到废纸篓。「打开存储文件夹」会在 Finder 中打开全部 GIF。录制完成会自动保存并复制，录制框下也可再次点击「复制 GIF」。选中作品后可查看实际像素尺寸、总帧数和文件大小。
- **Esc**：取消框选。
- 主窗口 → **快捷键设置…**：可分别自定义截图和 GIF 快捷键。点击要修改的快捷键并按下新组合键。

首次使用时，在主窗口点「申请录屏权限…」直达系统设置的「录屏与系统录音」，允许 snap-gif 后重新打开应用。屏幕区域以发起捕获时指针所在的显示器为准。主窗口可设置每秒 4、8、12 或 16 帧，以及 480、720 或 960 像素的最长边上限。实际尺寸不会放大超过所选区域的原始像素。复制 GIF 时，剪贴板提供动图数据和原文件，可粘贴到支持 GIF 或文件粘贴的应用。目标应用如果不接受 GIF 粘贴，可从图库打开存储文件夹并上传原文件。

GIF 默认存放于 `~/Library/Application Support/snap-gif/GIFs`。主窗口点「更改存储位置…」可选择其他文件夹，已有文件仍留在原位置。

需要 macOS 14 或更新版本。安装 Xcode Command Line Tools 后，可运行：

```sh
./build.sh
open build/snap-gif.app
```

## 安装与更新

从 [GitHub Releases](https://github.com/hydrogenhe/snap-gif/releases/latest) 下载适合你的 Mac 的 ZIP，解压后将 App 放到可写目录。需要 macOS 14 或更新版本，可选 Apple 芯片版（arm64）或 Intel 版（x86_64）。

下载和 App 内更新都无需 GitHub 登录。在主窗口点「检查更新…」会立即查询 GitHub。App 也会在启动时和每运行 6 小时自动检查。有新版时会弹出提示，点「是，下载并安装」才会安装并重新打开 App。点「否，暂不更新」后，同一版本不再自动提醒，仍可手动检查。v0.3.3 及更新版本可直接通过 App 升级。

当前安装包未经 Apple 公证，首次从浏览器下载并打开时，macOS 可能会拦截。参见 [Apple 的说明](https://support.apple.com/zh-cn/102445)。
